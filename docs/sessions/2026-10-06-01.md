## Behavior

Both quick and guided submissions stay on the default start screen. Live cards
appear with completed runs on Dashboard, AI Visibility and Search Visibility,
and in full history. Guided cards link to the existing review wizard when ready.
Shared step and elapsed-time helpers keep progress consistent. The start form
stays mounted at the quota limit, disabled, with reserved quota space.

Pending IDs are kept in session storage per user and organization; list updates
poll while work is pending and resolve omitted jobs individually. Transient
errors preserve the last known row; definitive missing responses settle tracking
with an explanation. Completed rows link to results and stop polling.

Details use a reversible CSS grid animation and respect reduced motion and
focus accessibility. The reported first-collapse jump was reproduced by loading
AI Visibility, scrolling to the bottom and closing details: the heading moved
104px because the browser clamped scrollTop as content shortened. The history
now temporarily preserves the minimum height needed for the current viewport,
releasing unused space as the user scrolls upward or expands again. Desktop and
mobile regression checks keep the heading, View all and toggle within 1px.
