  platform layer around the engine is missing. The parity scoreboard

  ~40 REQUIRED.
- **Four PRs merged outside the session process (2026-08-03/04):** #4
  (results-page visuals), #13 (account screens — P6.1 is therefore
  **merged**, not "in review" as the docs said), #23 (Site Audit backend:
  `seo_projects`/`site_audits`/`site_audit_pages`, authenticated APIs, a
  Chromium crawler + dedicated worker), and #11 (**the measured/simulated
  GEO pivot**: runner now calls `execute_measured` — `geo_mode=measured`
  = Tavily search + OpenRouter grounded answer, `simulated` =
  OpenRouter-only; adds `geo_records` (migration 0011), per-analysis
  citation summaries, an interventions engine + library, a reliability
  auditor, and OpenRouter/Tavily providers; ported from `kaira-geo-api`).
  #23 and #11 carried **no ADR, no session log, no plan card** — recorded
  as tech-debt **#54/#55**, with one possibly production-affecting edge
  (**operator B7**: `GEO_MODE=measured` + `DRY_RUN=0` requires
  `OPEN_ROUTER_KEY`/`TAVILY_API_KEY` in prod `deploy/.env`, unverified
  from a docs-only session).
- **The repo holds three unproductized differentiator seeds** no
  competitor exposes: the reliability auditor (per-claim evidence checks),
  the interventions library (insight→action), and grounded citation
  records. The differentiation proposal builds on them.

**What was produced:** the platform roadmap and its planning set — see §2.
