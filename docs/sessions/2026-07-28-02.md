## 3. Architectural changes

**ADR-26** in `design.md`. The decision worth re-reading before changing any of
it: the shared ASCII fold in `pipeline/textfold.py` is **case-preserving and
strictly 1:1**, and that is a correctness requirement, not a style choice.
`footprint.detect` matches against folded text but slices the user-facing
snippet out of the **original** by index. `casefold()` cannot be used —
`"İ".casefold()` is two codepoints (`i` + U+0307), which would shift every
snippet after an `İ` *and* stop `İşbank` matching `Isbank`. German `ß` is
excluded for the same reason (it expands to `ss`). Case-insensitivity comes from
`re.IGNORECASE`, which on `str` patterns is already Unicode-aware.

## 5. Assumptions and deviations (recorded as they were made)

1. **Scope was inferred, not given.** "Implement" was read as the proposal's
   "clear to build now" bucket (1, 2a, 3, 4, 5), not all six. The proposal
   itself argues the split, and reviving parked scope is not an engineering
   call. If the intent was all six, steps 2b and 6 are specified and small.
2. **The fold did not reuse `discovery._TR_FOLD` in place**, as the proposal
   instructed. It moved to a shared `pipeline/textfold.py`. The proposal missed
   the length-preservation constraint (§3); `_TR_FOLD` was only ever applied
   *after* `casefold()`, which does not preserve length. The intent — one map,
   not two — is honoured. Also: importing `discovery` from `footprint` would
   drag `httpx`/`bs4` into a module that is otherwise pure.
3. **Step 5 left two decisions open; both were taken and are documented.** The
   gate runs *after* the KYC step commits, so the offending profile stays
   inspectable on the failed row. Checker rows pass `analysis.category` as
   `known_topic`, because their brand/category are validated at submit time and
   a terse model reply must not fail a legitimate public submission — the
   empty-company half still applies to both paths.
4. **The dotted-`İ` fix overlaps skipped card P5.8's rule (a)** and shipped
   ungated, on the argument that it is a Unicode correctness bug affecting every
   language rather than a Turkish feature. P5.8's card lists it as Turkish, so
   this is written into that card *and* raised in operator A2 rather than left
   to be discovered in a diff. Rule (b) — suffix matching — was **not** built.
5. **`ruff format --check` fails on `tests/pipeline/test_discovery.py`.** This
   is **pre-existing** (verified against the pre-session tree) and outside every
   hunk added this session. CI gates on `ruff check` + mypy + pytest, not
   `format --check`, so it is not a break; left alone rather than bundling an
   unrelated reformat into a reviewable diff.
