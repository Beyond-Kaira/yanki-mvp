## Implemented and code map

- `backend/app/citations/evidence.py`: conservative HTTP(S) URL identity, unique
  search-rank lookup, inline source markers, boundary-safe domain matching.
- `backend/app/citations/report.py`: Pages/Domains aggregation from the original
  `Response.audit`; distinct response/prompt counts, correct denominators,
  provenance exclusions, model/group/search/ownership/opportunity filters,
  evidence and pagination.
- `backend/app/citations/schemas.py`: typed report, scope, coverage and evidence.
- `backend/app/api/routes.py`: additive citation-sources GET under existing
  `readable_analysis` authorization; bounded query parameters.
- `backend/app/pipeline/llm_analytics_measured.py`: authoritative search-source
  URL/title/domain; reject missing, ambiguous or invalid ranks/URLs rather than
  accepting model-generated source identity or guessing an array position.
- `backend/app/pipeline/geo_run.py` and `execute_measured.py`: explicit dry-run
  provenance on new runs, no migration.
- `frontend/app/ai-visibility/citations/CitationsClient.tsx`: ranking table,
  filters, distinct empty/error states, pagination and accessible evidence modal.
- `frontend/lib/citation-sources.ts`: API client and filtered CSV with provenance,
  denominator, filters, formula escaping and explicit truncation refusal.
- Generated `shared/contracts/openapi.json` and `frontend/lib/types.ts`; friendly
  type aliases in `frontend/lib/contracts.ts`.
- Tests: `backend/tests/test_citation_sources.py`, updated cross-tenant census,
  and `frontend/tests/citationSources.test.tsx`.
